# 工程版本与验证记录

本次整理保留两套应用源码的原始内容，没有合并差异或修改控制逻辑。主控配置为 STM32F103C8T6。

## 两套工程的关键差异

| 项目 | Keil MDK 工程 | STM32CubeIDE 工程 |
| --- | --- | --- |
| PA8 检测信号 | 自动模式以 `HCSR505_Get() == 0` 进入检测有效分支 | 自动模式以 `HCSR505_Get() == 1` 进入检测有效分支 |
| DHT11 初始化 | `main()` 调用 `DHT11_Init()` | `main()` 未调用该初始化函数 |
| 微秒延时 | `Delay_us()` 使用空指令循环 | `Delay_us()` 直接改写 SysTick 寄存器 |
| 温度模式读数 | 调用 `DHT11_Read()` 后继续控制 | 仅在读数返回 `HAL_OK` 时更新控制 |

`Core/Inc/DHT11.h`、`Core/Inc/stm32f1xx_it.h` 及六个同名 C 文件存在字节差异，部分仅为空白或注释变化。它们不能被当作只更换 IDE 的完全等价版本。

## 使用前需核对

- 原项目备注写 TCRT5000，器件表和图纸写 TCRT1000；代码符号却沿用 `HCSR505`。源码能够确认的是读取 PA8 电平，传感器实际型号、检测范围和接近效果需实物确认。
- `Speed` 使用 `int8_t`。自动湿度模式将计算结果赋值给该变量之后才判断 `> 100`，较高读数下存在超出变量范围的风险。此处仅记录待验证问题，未改变原始源码。
- CubeIDE 版微秒延时直接改写 SysTick 配置；它对 HAL 系统时基的影响需上板验证。
- 倒计时输入边界、编码器消抖、DHT11 失败时的电机行为未重新测试。
