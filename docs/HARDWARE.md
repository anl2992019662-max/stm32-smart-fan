# 硬件与接线

以下内容根据原始器件表、项目备注及 `Core/Inc/main.h`、定时器和 GPIO 配置整理。它记录工程使用的信号，不代表完成过实物验证。

## 器件清单

| 器件 | 数量 | 说明 |
| --- | ---: | --- |
| STM32F103C8T6 最小系统板 | 1 | 主控 |
| TB6612FNG 电机驱动模块 | 1 | A 通道驱动直流电机 |
| 130 直流电机 | 1 | 风扇电机 |
| DHT11 温湿度模块 | 1 | 3 引脚模块 |
| 0.96 寸 OLED 显示屏 | 1 | 4 引脚，软件 I²C 接口 |
| 带按钮旋转编码器 | 1 | S1、S2、KEY、VCC、GND |
| 独立按键 | 2 | 菜单移动与确认 |
| 反射式红外光电模块 | 1 | 备注为 TCRT5000，原始器件表和图纸为 TCRT1000，实际型号待核对 |
| KH-TYPE-C-2P 5V 接口 | 1 | 按实际供电方案选用 |

## 信号接线

| 信号 | STM32 引脚 | 工程用途 |
| --- | --- | --- |
| DHT11 DATA | PA0 | 温湿度读取 |
| TB6612FNG PWMA | PA2 / TIM2_CH3 | PWM 输出 |
| TB6612FNG AIN1 | PA4 | 电机方向控制 |
| TB6612FNG AIN2 | PA5 | 电机方向控制 |
| 红外模块 OUT | PA8 | 检测门控输入，代码沿用 `HCSR505` 名称 |
| 菜单移动按键 | PB0 | 按键另一端接 GND |
| 编码器 KEY | PB1 | 调速锁定切换 |
| OLED SCK/SCL | PB8 | 软件 I²C 时钟 |
| OLED SDA | PB9 | 软件 I²C 数据 |
| 菜单确认按键 | PB10 | 按键另一端接 GND |
| 编码器 S2 | PB14 | 外部中断输入 |
| 编码器 S1 | PB15 | 外部中断输入 |

原备注记录 TB6612FNG 的 AO1、AO2 接电机，STBY 接 3.3V，逻辑 VCC 接 3.3V，VM 使用电机电源。所有模块与主控共地。接线前按实际模块规格核对供电、输出电平及供电能力。

原始资料中的红外模块型号及两套代码的有效电平不一致。先核对实物和所用工程，再启用 PA8 门控，具体差异见 [版本说明](VERSION_NOTES.md)。
